# Pemetaan pengumpulan

| Instruksi | Berkas/lokasi |
|---|---|
| Source aplikasi atau link repository | `website/` dan URL repository setelah push berhasil |
| Skrip migrasi perubahan requirement | Empat skrip di `sql/` |
| File backup atau bukti lokasi backup | Paket final/backup SQL privat kelompok, di luar Git |
| Laporan PDF | Disusun kelompok menggunakan implementasi dan bukti aktual |

Laporan memuat gambar/deskripsi, CRUD, JOIN, perubahan requirement, debugging, backup dan recovery. Gunakan 26 tabel dasar dan 38 objek SQL total; source R05 berjumlah 66 berkas.

Identitas seluruh anggota/NIM, video 10–15 menit dan logbook kelompok dilengkapi sesuai tugas asli. GitHub tidak otomatis menyelesaikan komponen tersebut.

Repository Private memerlukan akses dosen/anggota. Pastikan penilai dapat membuka URL; alternatifnya sertakan source ZIP melalui kanal pengumpulan resmi.
